🌐 Consortium SI Corporate Website (Vx)

🎯 Context & challenge

This project demonstrates a Digital Project Manager approach with a business-analysis focus to build a clear, credible, and useful web channel for different target audiences (clients, partners, prospects).

The main objective: turn heterogeneous business expectations into clear user journeys and structured content.

🖼 Screenshots

Open live demo

🧪 Distinctive use case positioning

This case served as an internal experimentation field, with a single sponsor (myself) as the only source of requirements and structured execution through AI agents.

  • End-to-end steering framework tested across the full chain (brief, scoping, build, acceptance)
  • Multi-agent AI support to accelerate production and reviews
  • Refined custom instructions to maintain consistency of tone, structure, and quality

In this use case, project interactions are handled with AI agents representing roles, not with an operational human team.

No human stakeholder needs-assessment workshop was conducted for this case.

🏗 Technical anchoring (original version)

  • Information architecture and usage-driven page hierarchy
  • Navigation structuring, templates, and bilingual content logic
  • Performance/accessibility baseline for professional use
  • Structured correction iterations based on targeted feedback

🛠 Stack & platforms used

  • Front-end: React + Vite + TypeScript + Tailwind CSS
  • Navigation: React Router (SPA)
  • Form handling: EmailJS (without dedicated backend)
  • Versioning: GitHub (branches, merges, traceability)
  • Execution: VS Code + terminal for build, debug, and QA
  • Prototyping: Bolt.new and StackBlitz for rapid iteration
  • Deployment: Vercel (build, environment variables, continuous deployment)

🤖 AI-assisted project organization

The project was run as a multi-role setup, with central human steering and specialized AI agents by task.

  • Product steering: requirement scoping and prioritization
  • Front-end integration: UI component generation and iteration
  • Debug: rendering and routing issue diagnosis
  • Quality: build/lint checks and critical user-flow testing
  • Deployment: Vercel configuration and post-release checks

This approach demonstrates the ability to orchestrate AI operationally while keeping full project governance.

👤 BA / Digital Project Manager role

  • Collected requirements from the single sponsor (myself), then translated them into operational execution through role-based AI agents
  • Converted business objectives into site structure and user journeys
  • Formalized functional requirements for content and navigation
  • Coordinated design and web delivery

🧩 Project approach

1. UX and functional scoping

  • Internal prioritization sessions on key messages and usage hypotheses
  • Definition of page templates and editorial model
  • Preparation of an incremental delivery backlog

2. Delivery steering

  • Milestone tracking across design, integration, and validation
  • Arbitration between timeline, quality, and brand consistency constraints
  • Compliance checks against initial scope

3. Acceptance and continuous improvement

  • Test scenarios for navigation, content, and accessibility
  • Corrections prioritized by impact on user experience
  • Preparation of future improvements (bilingual scope, content enrichment)

📈 Deliverables and outcomes

  • Clear, usage-oriented information architecture
  • Reusable content framework for future pages
  • Baseline editorial governance to secure updates
  • Digital support aligned with the company positioning
