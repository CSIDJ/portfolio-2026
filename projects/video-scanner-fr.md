# 🎬 Outil d’Automatisation Vidéo — Workflow IA Structuré

## 🎯 Objectif

Concevoir un outil structuré d’automatisation pour l’analyse vidéo
et l’extraction de métadonnées,
intégrant des workflows assistés par IA
dans un environnement d’exécution contrôlé.

---

## 🏗 Vue d’Architecture

Composants principaux :

- Couche d’exécution Python
- Interface GUI (basée sur Tkinter)
- Validation structurée des entrées/sorties
- Logique de traitement modulaire

Workflow :

1. Ingestion vidéo
2. Extraction de métadonnées
3. Validation structurée
4. Reporting automatisé
5. Export & journalisation

---

## 🧠 Défis Techniques

- Gestion des dépendances locales
- Stabilisation de l’interface GUI sous Linux
- Gestion des modules système manquants (ex : tkinter)
- Structuration robuste de la gestion d’erreurs

---

## 🤖 Debug Orchestré par l’IA

Le projet s’est fortement appuyé sur l’assistance IA pour :

- Diagnostic des dépendances
- Stratégie d’isolation environnementale
- Debug progressif
- Simulation d’exceptions
- Refactoring du code

L’IA a agi comme :

- Relecteur technique
- Assistant de debug
- Générateur de documentation
- Conseiller environnemental

---

## 🛠 Compatibilité Linux

Validé sur environnement Fedora :

- Isolation via environnement virtuel
- Installation contrôlée des dépendances système
- Exécution maîtrisée
- Correction des erreurs via analyse de traces

---

- Application concrète d’outils IA
- Méthodologie de debug structurée
- Approche orientée automatisation
- Discipline d’exécution
- Expérimentation orientée livraison
